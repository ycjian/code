60–90 秒自我介绍（直接练熟）

我目前在 Adobe AI Infra 团队担任 Senior Software Engineer 和 Tech Lead，核心方向是多模态 AI 数据基础设施和生产 ML 平台。我最近设计了一个 context-aware AI infrastructure，把 media onboarding、retrieval、generation、semantic tagging 和 assistant workload 统一到共享执行层；其中包括统一的 intent/schema、dataset 和 artifact reference、policy check、runtime selection、异步任务路由，以及共享 CPU/GPU 资源治理。

此前我在 Adobe Search & Discovery 设计了面向 image、audio、video、3D 和 document 的 multimodal discovery platform，通过 Kafka、Flink、Milvus、Elasticsearch 和多云 Kubernetes 支持 50B+ assets，并通过 on-device pruning 和 hybrid edge-cloud execution 把 heavy-media payload transfer 降低 10–20x。更早在广告平台做过 100B+ opportunities/day 的实时 ML 系统。

这些经历和 XPENG 的问题很吻合：虽然 domain 从 creative assets 变成 driving logs，但底层仍是大规模 multimodal ingestion、metadata/index、distributed processing、dataset versioning、training data loading、failure recovery 和 continuous data flywheel。我希望把自己在平台抽象、规模化和 production reliability 上的经验，用到 VLA/world model 和自动驾驶 foundation model 的数据迭代上。

“为什么 XPENG / 为什么自动驾驶 AI Infra？”

我想做的是模型能力和真实世界数据之间的基础设施闭环。自动驾驶比一般内容平台更有挑战：数据是多传感器、强时序、长序列的，rare event 很重要；一个 dataset 不只是文件集合，还必须携带 calibration、ego pose、scenario、label、lineage 和 evaluation slice。模型在 closed-loop 中发现失败后，还要快速回流到 mining、curation、relabeling 和 retraining。

我的背景正好覆盖这个闭环需要的关键能力：大规模多模态数据、hybrid edge-cloud、分布式 pipeline、统一 artifact reference、检索、共享 CPU/GPU 资源和可观测性。对我来说这是一个自然的 domain expansion，而不是从零转行。
