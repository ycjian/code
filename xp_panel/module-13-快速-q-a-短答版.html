13. 快速 Q&A：短答版

系统与数据

Q：Batch vs Streaming？ A：fleet telemetry/manifest 和 failure trigger 需要 streaming freshness；重 decode、全量 backfill、dataset materialization 更适合 batch。常见是 streaming 发现和编排，batch 做重计算；统一 output contract 避免两套语义漂移。

Q：Throughput vs Latency？ A：训练 ingestion 通常 throughput 优先，可增大 batch/shard；failure detection 可能有 freshness SLO。按 workload class 区分，不做一个全局选择。

Q：Schema evolution？ A：schema ID/version 随 artifact；reader 兼容规则；additive change 优先；breaking change 新 version + backfill/migration；unknown field 保留；publish 前 contract test。

Q：如何做 replay？ A：raw immutable source + versioned event/manifest + deterministic transform + pinned code/env；side effect 与 compute 分离。Replay 结果写新 namespace/version，避免覆盖历史。

Q：如何做 deletion / privacy？ A：数据分类、最小权限、encryption、audit；identity/consent 与 artifact lineage 关联；删除请求沿 lineage 传播 raw/derived/index/cache，并通过 tombstone + verifier 证明完成。备份遵循 retention policy。

Q：如何 capacity plan？ A：从 daily ingest × retention × replication/index amplification 算 storage；从 bytes/s、decode cost/sample、shuffle amplification 算 compute/network；用 peak factor、failure headroom、backfill contention 和 growth rate，不只按平均。

ML / Dataset

Q：Data drift 和 concept drift？ A：data drift 是输入分布变，concept drift 是 P(y|x) 关系变。先按 ODD/scenario slice 监控，再结合 label/eval 判断；单看 embedding distribution 不能证明 concept drift。

Q：如何防 train/test leakage？ A：按 drive session/route/time group split；near-duplicate 检测；derived clip 继承 parent split；冻结 evaluation manifest；lineage gate 阻止同源样本跨 split。

Q：如何选择 long-tail data？ A：taxonomy coverage、uncertainty/disagreement、novelty、severity、diversity 和 expected utility；去重且保留 unbiased baseline，训练时记录 sampling weight。

Q：Annotation 如何扩展？ A：pre-label/auto-label → uncertainty/quality routing → human review → golden set audit；label schema/version、annotator/tool/model provenance 全记录；按 error slice 而不只按总体 accuracy 评估。

Reliability

Q：Retry policy？ A：错误分类、exponential backoff + jitter、retry budget、deadline；只有 idempotent/可补偿操作自动 retry；permanent error 进 quarantine/DLQ；避免 retry storm。

Q：如何 atomic publish dataset？ A：先写不可见的 files/manifest，校验 complete 后用单个 metadata pointer/transaction 将 version 变为 published。Reader 只读 published immutable snapshot。

Q：Leader 挂了怎么办？ A：lease + fencing token 防旧 leader 复活写入；状态在 durable store；新 leader 从 checkpoint/log 恢复。仅 heartbeat/TTL 不足以避免 split brain side effect。

Q：如何减小 blast radius？ A：tenant/workload isolation、separate execution pools、quota、circuit breaker、staged rollout、regional cell、dependency timeout/fallback；控制面故障不应打断已 materialize dataset 的训练读取。
